# Student Performance Dashboard

A student performance dashboard built using Python, Pandas, Matplotlib, and Streamlit.

## Features
- View student information and class statistics
- Analyze subject-wise and individual student performance
- Monitor student attendance
- View pass/fail results
- Filter and download student data

## Technologies Used
- Python
- Pandas
- Matplotlib
- Streamlit

## How to Run Locally

1. Clone this repository.
2. Install the required libraries:

   `pip install streamlit pandas matplotlib`

3. Run the application:

   `streamlit run app.py`

## Project Files
- `app.py` — Main dashboard application
- `students.csv` — Student dataset

## Purpose
This project demonstrates data analysis and visualization using Python.
